# interview-quetions

**Live site:** [https://htr3.github.io/interview-quetions/](https://htr3.github.io/interview-quetions/)

A static interview preparation site with notes, examples, and quick references across core backend and engineering topics.

## Topics

- **Java** — language fundamentals, collections, concurrency, JVM
- **Spring Boot** — REST APIs, security, data access, configuration
- **DSA** — algorithms and data structures for coding interviews
- **Microservices** — patterns, communication, resilience
- **System design** — scalability, trade-offs, architecture sketches
- **Production** — reliability, observability, deployment practices
- Plus **SQL**, **Kafka**, **DevOps**, **testing**, **behavioral**, and **projects**

Open `index.html` in a browser to browse the site locally.
