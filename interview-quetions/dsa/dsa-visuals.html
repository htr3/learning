1. Basic Concepts

Big O — growth rates

Compare how operations grow as input size n increases: O(1), O(log n), O(n), O(n log n), O(n²).

Recursion & backtracking — subset tree

Build all subsets of [1,2,3]: include or skip each element, then undo (backtrack).

2. Arrays & Strings

Array — indexing & insertion

Contiguous memory: O(1) access by index; inserting in the middle shifts elements — O(n).

Two Sum — HashMap lookup

For each value, check if (target − value) was seen. Store value→index in HashMap — O(n).

Sliding window — unique substring

Expand right, shrink left when duplicate found. Track last index per character.

Prefix sum — range query

prefix[i] = sum(nums[0..i]). Range [l,r] = prefix[r] − prefix[l−1] in O(1).

Two pointers — container with most water

left=0, right=n−1. Move the shorter line inward to possibly increase area.

3. Linked List

Reverse linked list — pointer rewiring

Watch prev, curr, and nxt. Each step: save nxt → curr.next = prev → advance. Orange arrows = flipped links.

Doubly linked list — prev & next

Bidirectional links enable O(1) delete at known node (e.g. LRU cache).

Floyd cycle detection — tortoise & hare

Slow +1, fast +2 per step. Meeting inside cycle proves a loop — O(n).

4. Stack & Queue

Stack — push & pop (LIFO)

Last In, First Out — undo stacks, DFS, parentheses matching.

Queue — FIFO enqueue & dequeue

First In, First Out — BFS, job buffers, thread pools.

Deque — both ends

Add/remove at front and back — monotonic deque for sliding window maximum.

5. Trees

Tree traversals — in / pre / postorder

Same tree, different visit orders. Inorder on BST yields sorted sequence.

Level-order BFS on tree

Queue processes all nodes at current depth before going deeper.

Binary search tree — insert & search

Left < root < right. Path length = tree height h — O(h).

6. Heap

Min heap — insert & heapify

Complete binary tree: parent ≤ children. Array index i → children 2i+1, 2i+2.

7. Hashing

Hash map — key to bucket

hash(key) % buckets → index. Average O(1) get/put when load factor is low.

Hash collisions — chaining

Multiple keys land in same bucket → linked list (or tree) at that slot.

8. Graphs

Graph — BFS vs DFS

BFS uses a queue (layers); DFS uses stack/recursion (depth first). Both O(V+E).

Dijkstra — shortest path

Min-heap picks closest unvisited node; relax edge weights. Non-negative weights only.

Topological sort — Kahn's BFS

DAG: repeatedly take node with indegree 0, reduce neighbors' indegree.

Union-Find — connected components

Kruskal MST: union sets when edge connects different components. Path compression optional.

Trie — insert & search

Prefix tree: each node stores char → child. Insert/search O(word length). ★ marks end of word.

9. Sorting & Searching

Sorting — step animator

Bubble, selection, insertion, merge, quick, heap sort. Orange = comparing, red = swapping, green = sorted.

Binary search — halving the range

Sorted array: compare mid, discard half. O(log n) time, O(1) space.

10. Dynamic Programming

Fibonacci — tabulation

dp[i] = dp[i−1] + dp[i−2]. Turns O(2ⁿ) recursion into O(n).

Kadane — maximum subarray

curr = max(nums[i], curr + nums[i]); track global best.

0/1 Knapsack — DP table

For each item, update dp[w] from larger capacities down to avoid reuse.

LCS — longest common subsequence

If chars match: dp[i][j]=1+dp[i−1][j−1]; else max of neighbors.

11. Greedy Algorithms

Activity selection — non-overlapping intervals

Sort by end time; greedily pick next compatible interval.

Fractional knapsack — by value/weight

Sort items by value/weight ratio; take full items then fraction of next.
