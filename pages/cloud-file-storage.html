Chunking Strategies

Fixed vs Content-Defined vs Whole-file vs Delta
The boundary-shift problem — with fixed-size chunks, inserting one byte at the start shifts every later boundary, so every chunk changes and nothing dedups. Content-defined chunking (CDC) places boundaries based on content (a rolling hash), so an insert only changes the local chunk — everything else still dedups. That's why Dropbox-style systems use CDC.
